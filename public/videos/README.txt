Place your local surprise video file here:
- Recommended filename: secret.mp4 (i.e. public/videos/secret.mp4)
- Supported formats: .mp4, .webm, .mov

If you use a different filename (e.g. videos/myvideo.mp4), you can change the path in "data/surprise.json" or through the "Customize Surprise Data" modal in the web app!
